How visual scores work · Subjective screenshot review / 100

Each full gameplay screenshot is judged on five criteria, each rated from 0 to 10: art direction (palette, identity, atmosphere), layout (balance, hierarchy, spacing), readability (text size and contrast), world rendering (planet detail, depth, map treatment), and polish (consistent typography, borders, icons, and finish).

Score = round(3 × art direction + 2.5 × layout + 2 × readability + 1.5 × world rendering + 1 × polish). Scale: 0 = absent or unusable, 5 = functional but visually basic, 7 = good with visible weaknesses, 9 = excellent, 10 = exceptional.

Based on eleven desktop gameplay screenshots, reviewed on 25 October 2026. Original captures are 1440 × 900; newer captures use the available desktop viewport, with full-page captures for Sol, reworked Astra, and GLM 5.3. These subjective ratings are not a controlled viewport benchmark. Ratings describe the captured view, including visible clipping; animation, other screen sizes, gameplay quality, model cost, and token usage are not assessed.
